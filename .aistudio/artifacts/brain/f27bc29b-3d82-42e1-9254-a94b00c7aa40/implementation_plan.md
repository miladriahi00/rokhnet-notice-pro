# طرح جامع نسخه ۲.۰ افزونه اطلاعیه و تعهدنامه هوشمند وردپرس (RokhNet Notice Pro v2.0)

این سند، نقشه راه ارتقای افزونه **RokhNet Notice Pro** به **نسخه ۲.۰.۰** (توسعه یافته توسط **میلاد ریاحی** · `09133062388` · [rokhnet.com](https://rokhnet.com)) بر اساس نیازمندی‌های جدید برای مدیریت چندگانه اطلاعیه‌ها، سرعت بارگذاری حداکثری، خوانایی کامل رنگ‌ها در تمامی استایل‌ها و تجربه کاربری مدرن در پیشخوان وردپرس است.

---

### تصمیمات تایید شده توسط کاربر (User Review & Confirmed Decisions)

> [!IMPORTANT]
> تمامی موارد زیر بر اساس دستور مستقیم و پاسخ‌های تایید شده شما در معماری نسخه ۲.۰ اعمال شده‌اند:

- **مدیریت چند پاپ‌آپ و اولویت نمایش**: امکان تعریف بی‌نهایت اطلاعیه مجزا با قابلیت افزودن، ویرایش، حذف، کپی (Duplicate) و تغییر وضعیت فعال/غیرفعال. در صورت تطابق همزمان چند پاپ‌آپ در یک صفحه، نمایش بر اساس **اولویت (Priority) و نوبت** انجام می‌شود (پس از تایید پاپ‌آپ اول، پاپ‌آپ بعدی در صف یا در بازدید بعدی نمایش می‌یابد).
- **انتخاب صفحات هدف و لود شرطی (Zero-Speed Impact)**: انتخاب ترکیبی صفحات (کل سایت، صفحه اصلی، برگه‌های ووکامرس شامل فروشگاه/محصول/سبد خرید/تسویه‌حساب، دسته‌بندی‌ها و یا وارد کردن آدرس URL / شناسه ID برگه‌های خاص). فایل‌های CSS و JS افزونه **فقط و فقط در صفحاتی که پاپ‌آپ فعال دارند** لود می‌شوند و در سایر صفحات سایت هیچ فایلی تزریق نمی‌شود.
- **عدم سنگین شدن دیتابیس (Zero DB Bloat)**: حذف کامل جدول لاگ دیتابیس (`wp_rnp_acknowledgements`) و حذف درخواست‌های AJAX سمت سرور هنگام تایید کاربر؛ وضعیت تایید هر پاپ‌آپ به صورت ۱۰۰٪ سبک در **کوکی مرورگر و LocalStorage** کاربر بر اساس شناسه و نسخه همان پاپ‌آپ ذخیره می‌شود.
- **ارث‌بری کامل فونت از قالب وردپرس**: حذف هرگونه فونت خارجی از فایل‌های افزونه وردپرس و استفاده از `font-family: inherit` تا پاپ‌آپ دقیقاً با فونت فارسی قالب فعال وردپرس و تنظیمات تایپوگرافی سایت نمایش داده شود.
- **تطبیق هوشمند رنگ‌ها و خوانایی ۱۰۰٪ در تغییر استایل**: با تغییر هر یک از ۵ استایل (شیشه‌ای، دارک طلایی، مینیمال روشن، نئون سایبری، فروشگاهی ووکامرس)، تمامی رنگ‌های پس‌زمینه، متن اصلی، زیرعنوان، کادر محتوا، کادر چک‌باکس و دکمه‌ها به صورت خودکار تنظیم می‌شوند تا در استایل‌های روشن و تیره، بالاترین کنتراست و خوانایی حفظ شود.
- **نمایش قطعی آیکون‌ها در فرانت‌اند وردپرس**: رندر مستقیم کدهای برداری (Inline SVG) برای تمامی آیکون‌ها در کلاس PHP فرانت‌اند (`class-rnp-frontend.php`) تا بدون نیاز به فونت‌آیکون خارجی در تمامی قالب‌های وردپرس نمایش داده شوند.
- **کنترل فعال/غیرفعال‌سازی تک‌تک اجزای هدر**: افزودن سوییچ مجزا برای نمایش یا عدم نمایش:
  1. آیکون پاپ‌آپ (`showIcon`)
  2. سوتیتر / بج بالای عنوان (`showBadge`)
  3. عنوان اصلی (`showTitle`)
  4. زیرعنوان توضیحی (`showSubtitle`)

### ۱. نمای کلی و ارزش نسخه ۲.۰ (Overview & Core Concept)

- **چه کاری انجام می‌دهد**: به مدیر سایت وردپرس و فروشگاه ووکامرس اجازه می‌دهد به جای یک پاپ‌آپ ثابت، چندین پاپ‌آپ هدفمند با استایل‌ها و قوانین مجزا تعریف کند (مثلاً یک پاپ‌آپ با تم روشن رسمی برای قوانین تسویه‌حساب ووکامرس، یک پاپ‌آپ شیشه‌ای برای اطلاعیه صفحه اصلی و یک پاپ‌آپ برای دسته‌بندی محصولات خاص).
- **مزایای فنی کلیدی**:
  - **سبکی مطلق دیتابیس**: ذخیره کل پاپ‌آپ‌ها در یک کلید بهینه `rnp_notices_v2` بدون ایجاد جدول اضافی یا رکوردهای حجیم در `wp_usermeta` و دیتابیس.
  - **سرعت لود ۱۰۰ از ۱۰۰**: بررسی شروط نمایش در سمت سرور (PHP) پیش از فراخوانی `wp_enqueue_scripts`؛ اگر صفحه‌ای پاپ‌آپ فعال نداشته باشد، حجم کدهای لود شده افزونه در آن صفحه **صفر کیلوبایت** است.

### ۲. تجربه کاربری و طراحی بصری (User Experience & Visual Design)

#### بهبودهای داشبورد و استودیو:
1. **مدیریت چندگانه اطلاعیه‌ها (Multi-Notice Sidebar & Bar)**:
   - نمایش لیست تمامی پاپ‌آپ‌های تعریف شده به همراه وضعیت (فعال/غیرفعال)، اولویت نمایش، استایل انتخاب شده و صفحات هدف.
   - دکمه‌های عملیاتی سریع: «+ افزودن اطلاعیه جدید»، «کپی کردن»، «حذف اطلاعیه» و «تغییر وضعیت فعال/غیرفعال».
2. **سیستم رنگ‌بندی تطبیقی با کنتراست تضمین‌شده (Contrast-Safe Palette Engine)**:
   - هر استایل دارای پالت کامل شامل: رنگ پس‌زمینه کارت (`bgColor`)، رنگ متن عنوان و بدنه (`textColor`)، رنگ پس‌زمینه باکس اسکرول متن (`bodyBoxBg`)، رنگ حاشیه باکس متن (`bodyBoxBorder`)، رنگ باکس چک‌باکس (`checkboxBg`)، رنگ اصلی دکمه (`primaryColor`) و رنگ متن دکمه (`buttonTextColor`) است تا مثلاً در استایل روشن «مینیمال رسمی» یا «دارک طلایی»، متن‌ها کاملاً واضح و خوانا باشند.
3. **پیش‌نمایش زنده چندحالته**:
   - امکان سوییچ فوری بین اطلاعیه‌های مختلف در شبیه‌ساز زنده.
   - تست نمایش نوبتی (Queue Simulation) وقتی بیش از یک اطلاعیه برای یک صفحه فعال است.

### ۳. معماری فنی نسخه ۲.۰ افزونه وردپرس

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    RokhNet Notice Pro v2.0 Architecture                 │
├───────────────────────────────────┬─────────────────────────────────────┤
│   WordPress Admin Dashboard       │   Conditional Frontend Engine       │
│  - Multi-Notice CRUD Manager      │  - Server-Side Page Matcher         │
│  - Per-Notice Style & Color Sync  │  - Zero Enqueue on Non-Target Pages │
│  - Header Elements Toggles        │  - Theme Font Inheritance (inherit) │
│  - Page / URL / ID / Woo Selector │  - Inline SVG Icon Renderer         │
│  - Priority & Queue Ordering      │  - Priority Queue JS Controller     │
│  - Single Option Storage (No SQL) │  - Pure Cookie/LocalStorage State   │
└─────────────────┬─────────────────┴──────────────────┬──────────────────┘
                  │                                    │
                  ▼                                    ▼
         wp_options['rnp_notices_v2']         Browser Cookie / Storage
         (Lightweight JSON Array)             (Zero Database Bloat)
```

#### نحوه عملکرد موتور انتخابی صفحات در PHP (`class-rnp-frontend.php`):
- هنگام اجرای قلاب `wp`، کلاس فرانت‌اند لیست اطلاعیه‌های فعال را به ترتیب فیلد `priority` مرتب می‌کند.
- برای هر اطلاعیه، شرط تطابق صفحه فعلی بررسی می‌شود:
  - `all_pages`: تمام صفحات سایت
  - `homepage_only`: `is_front_page() || is_home()`
  - `woo_checkout_cart`: `is_checkout() || is_cart()`
  - `woo_shop_product`: `is_woocommerce() || is_shop() || is_product() || is_product_category()`
  - `selected_pages`: بررسی تطابق آیدی برگه/محصول فعلی (`get_queried_object_id()`)، اسلاگ یا تطابق دقیق/بخشی آدرس URL فعلی با لیست صفحات انتخابی، و همچنین بررسی لیست صفحات مستثنی شده (Excluded URLs/IDs).
- تنها اطلاعیه‌هایی که با صفحه فعلی تطابق دارند در خروجی رندر می‌شوند و اگر آرایه خروجی خالی باشد، هیچ فایل CSS یا JS در صفحه لود نخواهد شد.
